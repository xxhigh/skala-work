1. 토크수가 낮거나 높으면 고장
2. RPM이 높아지면 마모가 심화
3. 온도가 과하게 높아지면 고장이 날것이다. (가공온도 - 실내온도)
4. 기계를 오랫동안 사용하면 공구가 마모될 것이다. (기존의 단일 변수가 있음)

토크+회전수

- 가설: 토크 수가 낮아지거나 높아지면 고장이 발생할 것이다.
- RotationSpeed_Torque_Ratio = (Rotation Speed / Torque)
- 회전 속도 대비 토크를 나타내 기계에 가해지는 상대적인 부하를 보고싶었습니다. 회전속도가 낮고 토크가 높거나, 회전속도가 높고 토크가 낮으면 고장이 발생할 확률이 증가했습니다. 단일 변수로 봤을 때보다 두 변수의 비율로 보았을 때 고장/정상 구분을 더 잘 보였습니다.

```py
# 다음은 고장 유형임 (0과 1로 표현)
# TWF: 공구 마모 고장
# HDF: 열 방출 고장
# PWF: 전력 고장
# OSF: 과부하 고장
# RNF: 무작위 고장
```

- TWF: 마모로 인해 무뎌져서 제대로된 제품이 생산이 안되는 상황
- HDF: 가공온도가 너무 높아져서 기계에 무리가 가는 상황
- PWF: 적정 전력이 공급되지 못해 기계가 작동을 멈추는 상황
- OSF: 공구가 한계치를 넘어선 상황에서 힘이 들어와 작동을 멈추는 상황
