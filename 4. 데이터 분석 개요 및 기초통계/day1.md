# 데이터 분석

## 혁신이란?

기업 경영에서 혁신은 **기존의 자원이 부를 창출**하도록 새로운 능력을 부여하는 활동이다.

### 경영 혁신

- 조직의 목적을 달성하기 위해, 새로운 생각이나 방법으로 기존 업무를 다시 기획/실행/평가 하는 활동
- 사업 구조 개선
- 프로세스 개선
- 혁신 이후, 정량적인 변화를 나타낼 수 있어야함. (A/B테스트, 데이터)

### 경영 혁신 활동에 정보/데이터 활용

- KPI
    - 조직의 목표 및 성과를 계량화하여 측정
- Six-Sigma
    - 제조 산업에서 시작된 품질 관리 활동을 고객 만족도/서비스 등의 영역으로 확장

-> "성장 기회 최대화" - "위험 발생 최소화" = 기업의 잠재가치 극대화

### 결측치 처리

결측치: 존재하지 않거나 관측되지 않음을 구분

- 비즈니스 관점에서 제외해도 되는지 반드시 검토 필요
- 다른 값으로 대체 시 "0, Average, Moving Average" 등

### 이상치 처리

이상치: 대다수 데이터와 달리 통계 관점에서 벗어난 값

- 비즈니스 관점에서 필요한 데이터인지, 재처리가 필요한지 확인
- 분석 목적에 필요한 데이터인지 판단
- 이상치 구분을 위한 파생변수가 필요한지 검토

## 통계(Statistics)

Descriptive Statistics
데이터의 기본적인 특징을 통계 기법을 활용해 확인

### 중심화

- _평균_
- _중앙값_
- 최빈값
- _이동평균_

#### 평균 vs 중앙값

평균은 이상치에 민감: 새롭게 추가된 데이터가 기존의 데이터 셋에 비해 너무 크거나, 작으면 전체 평균을 그 방향으로 이끔.

중앙값은 이상치에 둔감: 새롭게 추가된 데이터가 기존의 데이터 셋과 상관없이 미세하게 이동하거나, 변하지 않음.

> 둘 중 어떤 것을 쓸지는 데이터를 보고 사람이 판단하는 영역.

#### Moving Average

일정한 구간의 데이터를 평균 내어 전반적인 추세를 파악하는데 유용 = 시간이 지나면서 데이터 크게 어디로 움직이고 있는지 쉽게 파악 가능

장점

- 변동성 완화: 데이터의 급격한 변동을 부드럽게 만듬
- 추세 파악 유리
- 계산이 간단하고 직관적

활용 시 주의사항

- 지연 발생: 실제 변화보다 항상 늦게 반응(당연하죠)
- 이상치에 민감할 수 있음(단기 평균일 경우 영향이 매우 큼)
- 적절한 윈도우 크기 선택이 중요: 너무 크면 흐름이 느리고, 너무 짧으면 잡음이 반영됨.

### 퍼짐

- _표준편차_
    - 평균 중심으로 퍼짐 정도
    - 0에 가까우면 평균 근처 집중
- 변이계수
- _사분위수/사분위수 범위_
    - 작은 값 ~ 큰 값 나열하여 25%, 50%, 75% 위치하는 값 계산
    - IQR: 중앙값 좌우로 동일한 백분율 가진 두 점 간의 거리
- 범위/최소,최대

#### 편차, 분산, 표준편차

- 편차(Deviation): `D = 실제값 - 평균`
    - 실제 값이 평균으로부터 얼마나 차이나는가?
    - 그러나 퍼짐의 차이를 확인할 수 없다. (산술평균이 대부분 0으로 수렴)

- 분산(Variance): `V = D^2 = (실제값 - 평균)^2`
    - 퍼짐의 상태 그대로 나타내는 값 / 제곱을 하기 때문에 Length만 남음.
    - 그러나 퍼짐 상태라 하기에는 수치가 너무 커짐
    - 단위가 변경됨. (제곱)

- 표준편차(Standard Deviation): `Std = root(V) = root((실제값 - 평균)^2)`
    - 편차의 제곱평균
    - 기존 분산의 문제점을 보완하여 해석 가능한 수치로 바뀜
    - 단위가 바뀌지 않음.

#### 사분위수, N-Quantile

데이터를 동일한 비율로 잘라서 비교 가능한 기준을 만들기 위함. 평균이 놓치는 분포의 특성을 더 잘 파악.

사분위수: X의 분포를 확률적으로 균등하게 4개로 자른 개념. '데이터 개수 기준'으로 줄을 세워서 25%, 50%, 75% 지점에서 칼로 자른 지점.
N-Quantile: X의 분포를 확률적으로 N개의 균등한 조각으로 구분

#### 변이계수

- 평균치가 다른 집단이나 단위가 서로 다른 변수 퍼짐을 비교
- 상대적인 퍼짐
- 변이계수(c) = 표준편차 / 평균
- 값이 작을수록 평균치 가까지 분포

### 분포/대칭

#### 왜도(Skewness)

- 분포가 대칭을 벗어나 한쪽으로 치우친 정도
- 분포의 비대칭 방향/정도
- 정규분포는 대칭이므로 왜도 = 0
- 값이 클수록 비대칭 정도가 커짐

#### 첨도(Kurtosis)

- 특정 지역의 퇴적층의 특정 입자의 크기가 고른 정도
- 분포의 뾰족한 정도
    - 값: 0 = 중첨, 음수 = 평첨(평평), 양수 = 급첨(뾰족)
- 값이 클수록 그룹의 동질성 강함.

### 정규분포

#### 연속확률분포

정규분포: N(μ, σ2) μ : 평균, σ : 표준편차

- 봉우리가 하나이며, 좌우 대칭이고 종 모양인 곡선
- 곡선과 x축 사이의 면적은 1

### 데이터 변환

단위/분포 표준화를 통해 집단 간 비교 가능, 분석 모형 개발 시 Scale 차이 효과 제거

Z변환:

```
Z = x - m / s

# x: 관측값
# m: 평균
# s: 표준편차
```

Min-Max Scaler:

```
Z = x - min / max - min

# x: 관측값
# max: 최대값
# min: 최소값
```

#### 데이터 인코딩 주의사항

one-hot > sparse 해지

- 그러나 부스팅 계열 알고리즘에서는 성능이 떨어짐.
- 모델링 왜곡을 만들어 낼 수 있음.
