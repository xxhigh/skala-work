## 상관관계

- 두 변량 중 한쪽이 증가함에 따라, 다른 한쪽이 증가 또는 감소할 때의 두 변량의 관계 (1:1 관계)
- 두 변량이 얼마나 **선형적 관계**가 있는지 알아내는 것

> _인과관계_
>
> - 어떤 선형사실(원인)과 후행사실(결과)의 필연적 관계
> - 당연하지만 인과랑 상관은 다름. 표현할 때 구분해서 표현하기.

### 상관관계 분석

`변수 간 상관관계 분석`
변수 간의 상관관계 분석을 통해 모형 개발에 필요한 유의미한 변수를 선정하는데 활용

- 종속변수, 독립변수 간 상관관계 파악

`개체 간 유사성 분석`

- 기술적으로는 나쁘지 않음. 그러나...
- Y값이 없음. 그래서 실무에선 잘 안씀.

`기법`
범주형 데이터: **교차표**
연속형 데이터: **상관계수**, 공분산, 산점도

### 상관계수

**표준화된 공분산**: 공분산을 각 변량의 표준편차로 나누어 표준화

두 변량 사이의 관계가 얼마나 강한지 나타내는 숫자 (-1 <= p >= 1)

- 양의 값: 두 변수가 같은 방향으로 움직임
- 음의 값: 두 변수가 반대 방향으로 움직임
- 0: 선형관계 없음.

**상관계수 해석 시 유의사항**

- 그냥 값만 보지말고, 그래프를 그려서 보자.
- 이상치에 민감하게 반응하므로 제거 후 상관관계 분석을 진행하는 것이 필요.
- 상관관계는 메인스트림을 보는 것이지, 특이점을 보는 것이 아님.
- 상관계수 통한 결과 해석 시 교란요인에 대한 주의가 필요함.
- 상관계수 통한 결과 해석 시 시간 선/후 관계에 대한 주의가 필요함.

## 회귀분석(Regression Analysis)

`한참 돌다보면 제자리로 돌아온다.`
종속변수와 독립변수 사이의 **변화에 따라 회귀한다.** -> 두 변수 사이의 인과관계를 살펴본다.

변수들 간의 **상호 관련성을 규명**하고, **어떤 변수들의 변화로부터 다른 변수들의 변화를 예측**하는 통계기법

- 변수들이 서로 인과관계가 있는가?

- 관계가 있다면 얼마나 밀접한 관계인가?

- 관심이 있는 하나의 변수가 다른 변수들에 의하여 얼마나 잘 예측될 수 있는가?

### 회귀분석 기본 가정

1. _선형성_
2. _다중공선성(독립성)_
3. 정규성
4. 등분산성

4가지의 가정은 지켜야하지만, 실제 업무에서는 지키는 데이터가 나오기 어려움. 이태릭으로 표시한 것만 신경쓰도록 하자.

#### 1. 선형성

독립변수-종속변수 관계가 1차 함수라는 가정을 전제로 함. (직선의 형태)

`선형성을 만족하지 않는 경우 대응 방법`

1. 종속변수 변환
2. 상관분석 또는 데이터 값 조정

#### 2. 다중공선성

독립변수 간에 강한 상관관계가 있음 (|상관계수| >= 0.6)
다중공선성이 발생한 변수들 중 하나를 제거하거나 변수들을 결합하여 새로운 변수를 생성하여 다중공선성 제거

`다중공선성 확인 및 처리 방법`

1. 상관계수를 확인
2. 발생한 독립변수 중 하나만 남기고 삭제 또는 독립변수를 결합하여 새로운 변수 생성

### 회귀선

회귀분석: 회귀식을 찾아내는 것
회귀식: 독립변수와 종속변수의 관계
```
y = a1∙x1 + a2∙x2 + … + an∙xn + b
```

잔차: 관측값과 예측값의 차이


> 최소제곱법
>
> 회귀식을 찾는 방법 중 하나, 잔차 제곱의 합이 최소가 되게 하는 하나의 선을 두 변수 간의 상관관계를 나타냄
> sigma(관측값 − 예측값)2 → 𝑀𝐼𝑁

### 로지스틱 회귀분석

- 종속변수가 2 또는 3개 그룹으로 나누어진 경우
- 두 그룹이 구분되는 특성을 파악하여 "어느 그룹(정상/비정상)"에 속하는지를 예측

- S자 형태
- 입력값이 커져도 일정한 한계(0~1) 안에서 변화
- 값이 작을수록 "0"에 가까운 확률을 가짐
- Threshold(0.5)를 기준으로 사용 - 물론 도메인에서는 변경가능.

`로지스틱 곡선이 필요한 이유`

- 선형 회귀분석은 0~1 사이로 제한하여 확률로 표현할 수 없음. 그렇기 때문에 로지스틱을 활용해 해석함.
- 현실 문제를 풀기 위해 일정한 범위를 벗어나지 않도록 제한.
