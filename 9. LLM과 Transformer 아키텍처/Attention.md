
## 용어 정리

### 1. 문장

사용자가 입력한 문자열 그 자체.
### 2. 토큰(token)

문장을 나눈 처리 단위

예시)
```
"나는 사과를 먹었다" -> ["나는", "사과를", "먹었다"]
```

### 3. 임베딩(embedding)

단어나 토큰을 신경망이 계산할 수 있는 숫자 벡터로 바꾸는 것

예시)
```
"고양이" -> [0.2, -0.7, 0.4, 0.1]

"강아지" -> [0.3, -0.6, 0.5, 0.1]
```

### 4. 소프트맥스(softmax)

여러 숫자를 받아서 합이 1인 비율로 바꿔주는 함수를 말함.

예시)
```
// Attention이 받은 단어 세 개의 점수
고양이: 3.0
강아지: 1.0
자동차: 0.5

// 이렇게 값이 오면 뭐가 얼마나 중요한 지 모름. 그래서 변환이 필요
// 이 값을 확률처럼 해석할 수 있는 가중치가 됨.
고양이: 0.82
강아지: 0.11
자동차: 0.07
```

### 5. 어텐션(Attention)

현재 내가 처리하는 단어와 관련 있는 다른 단어를 찾아서, 중요한 정보는 많이 가져오는 방식

예시)
```
"철수는 영희에게 책을 주었다. 그는 집에 갔다."

// 위 문장에서 "그는"을 이해하기 위해서 모델이 앞의 단어들을 살핌.
철수 -> 중요
영희 -> 어느 정도 연관
책 -> 낮음
주었다 -> 낮음

// 이러한 관계의 중요도를 계산하는 것이 바로 어텐션
```

### 6. 셀프 어텐션(Self-Attention)

하나의 문장 내부에서 서로를 Attention하는 것

예시)
```
"나는 오늘 학교에 갔다"

// 위 문장에서 "갔다"가 다른 단어를 참고한다고 보면
"갔다" -> "나는"
"갔다" -> "오늘"
"갔다" -> "학교에"
"갔다" -> "갔다"

// 또 다른 단어 "학교에"가 다른 단어를 참고한다면
"학교에" -> "나는"
"학교에" -> "오늘"
"학교에" -> "학교에"
"학교에" -> "갔다"

// 즉 모든 토큰이 같은 문장의 다른 토큰들과 관계를 계산
```

### 7. 트랜스포머(Transformer)

Self-Attention을 핵심으로 사용하는 신경망 구조 전체

```
입력 토큰
임베딩
셀프 어텐션
피드 포워드
노멀라이제이션
...

// 이러한 블록을 여러 층 쌓은 구조가 트랜스포머
```
