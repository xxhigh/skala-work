착수.기획 - 프로젝트 목표 정의
분석.설계 - 요구사항 정의서 작성, UI/UX 설계, 디비 설계, API 설계

산출물
- 프로젝트 기술서
	- 요구사항 정의서
	- 화면 설계서
- 데이터 모델링
- API 명세서
- 발표자료

서버 인프라 환경, 예산, 일정은 제외시킴.


요구사항 정의서
1. 기본정보
	- 프로젝트명 / 작성자 / 작성일자 / 버전
	- 요구사항 아이디: 식별 코드
	- 분류: 회원관리, 결제, 대시보드 등
2. 기능 요구사항
	- 시스템이 무엇을 해야 하는지 직접적인 기능 설명
	- 요구사항명: 해당 기능의 대표 명칭
	- 상세 설명: 기능의 작동 방식, 출력 결과, 입력 값, 예외 처리 조건
	- 수요자/요청자: 해당 기능 요청 주체 (고객사, 마케팅팀)
	- 우선순위: H / M / L
	- 난이도 및 공수: 상 중 하 / 예상 Man-Day
3. 비기능 요구사항
	- 이번 프로젝트에서는 크게 고려하지 않음.
