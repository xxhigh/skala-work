## Association Rule

- 데이터 안에서 어떤 항목들이 함께 등장하는 패턴을 자동으로 찾아내는 분석 기법

### 연관규칙분석
- 동시 구매 품목에 관심
- 예시
	- 금요일에 기저귀를 산 남성고객은 맥주도 함께 산다 -> 연관규칙 표현: {남성, 금요일, 기저귀} -> {맥주}
### 순차분석
- 순서에 따른 규칙에 관심
- 예시
	- `구독 서비스` 액션 영화 -> 액션 드라마 -> 범죄다큐

### 평가 지표

![[009_Association.png]]

- 지지도: 데이터에서 흔한 패턴인지 확인가능
- 신뢰도: B 자체가 원래 많이 팔리는 상황에서는 과대평가 주의
- 향상도: 양의 연관성(Lift > 1), 음의 연관성(Lift < 1)

## PCA(Principal Component Analysis)

- 주성분 분석: 변수를 축소하여 자료를 설명하는 기법

## Anomaly Detection

- 대다수의 데이터와는 다른 특이한 패턴이나 비정상적인 징후(Outliers)를 찾아내는 분석 기법
- Feature Engineering의 이상치 탐지와 다른 것은, 이것은 이상징후를 탐지하는게 목적이고, EDA에서 찾는 이상치 탐는 모델의 성능을 올리기 위해 하는 작업임(꼭 성능이 향상되는 것도 아님.)
- 타겟 데이터가 없거나, 건수가 적은 경우가 좀더 일반적인 상황.

## 딥러닝

- 인간의 뇌를 본 따서 만든 인공신경망을 이용하여 학습하는 것.

### Summary

- 아래 단계를 반복

| 단계         | 역할                     | 비고               |
| ---------- | ---------------------- | ---------------- |
| 1단계: 순전파   | 신경망 구조로 예측값 생성         | 학습 모델 구조         |
| 2단계: 손실 계산 | 예측값 vs 실제값 비교 -> 손실 계산 | 얼마나 틀렸나?         |
| 3단계: 역전파   | 손실 vs 가중치 비교 -> 기울기 계산 | 어느 가중치 책임인가?     |
| 4단계: 경사하강법 | 가중치 업데이트               | 가중치를 어떻게 수정할까?   |
| 5단계: 학습률   | 가중치 업데이트               | 얼마나 크게 움직일까?     |
| 6단계: 옵티마이저 | 가중치 업데이트               | 더 똑똑하게 움직이는 방법은? |

### 인공 신경망 구조

입력 -> 가중치 -> 가중합 -> 활성함수 -> 출력

![[013_DeepL.png]]

1. 입력 값(x1, x2, ...)이 들어옴
2. 가중치(중요도 w1, w2, ...)를 곱하고
3. 가중합 계산. 여기까지는 회귀분석의 선형결합과 동일
4. 활성함수를 통과해서 (비선형 변환)
5. 최종 출력

### 활성 함수

- 모델에 곡선 표현 능력을 부여하는 역할
- 인공신경망에서 뉴련의 출력을 결정하는 비선형 함수
- 출력은 정규화로 이루어짐 (0~1, -1~1)
#### 종류

![[014_activeFunc.png]]

- `Sigmod`: 출력층에서 확률로 사용 (0, 1)
- `Tanh Function`: RNN, LSTM의 은닉층 (-1, 1)
- `ReLU`: CNN의 은닉층 (현재 표준) \[0, 무한대)

### 단층 퍼셉트론

- 초기 인공 신경망
- 입력층과 출력층으로만 구성된 구조
- 단순하지만 딥러닝의 출발점

=> U자 패턴, XOR 문제가 해결이 안됨

### 다층 퍼셉트론

- 여러 층의 퍼센트론을 쌓아 복잡한 문제 해결
- 은닉층이 추가되어 비선형 문제 해결
- XOR 문제 해결 가능

## 딥러닝 학습 원리

### 다층 퍼셉트론 가중치 결정 과정

입력층 -> 은닉층 -> 출력층

초기 가중치는 랜덤으로 시작
예측 결과와 실제 정답을 비교
오차(손실함수)를 계산하고
오차를 뒤로 전달하면서 가중치를 수정
이 과정을 '역전파'

> **딥러닝에서 학습이란 가중치 값을 조정해 가는 과정**

### 손실 함수

**손실이 작아질수록 모델이 잘 맞춘다는 의미**

- 오차: 실측값 - 예측값
- 손실 함수는 오차를 이용하여 모델이 얼마나 틀렸는지를 수치화하는 함수
- 회귀 -> MSE, 분류 -> Cross Entropy
- 오차를 줄이기 위해서 각 가중치와 오차의 관계를 찾는 것이 `역전파` 과정

### 역전파

**각 가중치의 손실 책임을 찾는 과정**

- 출력층에서 입력층으로 거꾸로 가면서, 각 가중치가 손실에 얼마나 영향을 미치는지 계산하는 과정
- 영향도를 알기 위해서 각 가중치의 기울기를 계산: `기울기 = 손실의 변화량 / 가중치의 변화량`

### 손실 지형도

가중치에 따른 손실값의 지도

![[015_LossLandscape.png]]

- 각 가중치 조합마다 손실값이 달라짐
- 모델 가중치에 따라 손실이 어떻게 변하는지를 보여주는 지도가 손실 지형도
- 손실지형도에서 오차가 최소값인 지점을 찾아가는 과정을 `경사하강법` 이라 함

### 경사하강법

- 손실이 최소인 지점을 찾아 가중치를 업데이트하는 기본 원리
- 최소 시작점에서 얼마나 큰 걸음으로 이동할지를 결정하는 것이 `학습률`
- 무작정 내려가는 것이 아니라 영리하게 이동하는 노력이 `옵티마이저`

### 학습률

가중치를 얼마나 크게(또는 작게) 업데이트할지 결정하는 값

- 0과 1 사이의 값을 가지며, 사람이 직접 설정
- 작을수록: 학습시간이 오래 걸림
- 클수록: 손실함수 그래프 지점을 벗어나는 경우가 발생
- 초기에는 큰 스텝, 최적화 포인트에 가까울 수록 작은 스텝으로 조절는 방법 -> 스케쥴러
- 손실의 변화량 / 가중치의 변화량 = 기울기

#### 스케쥴러

![[017_schduler.png]]

학습률을 시간에 따라 조절하여 빠른 탐색과 안정적 수렴을 동시에 달성하는 기법
- 옵티마이저는 가중치별 학습률을 조절하는 것
- 스케쥴러는 학습 진행 상황에 따라 전체 학습률을 동적으로 조절하는 기법
