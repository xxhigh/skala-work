## 머신러닝이란?

데이터로부터 스스로 **학습**하는 알고리즘
- 딥러닝: 인간의 뇌 구조를 본뜬 '인공 신경망'을 사용하여 데이터를 학습하는 알고리즘
	- 생성형 AI: 데이터를 학습하여 새로운 콘텐츠를 생성하는 일종의 인공지능 기술

### 기계의 학습이란?
- 입력: 데이터(숫자, 이미지, 텍스트)
- 처리: 수학적 알고리즘 기반 학습, 인공 신경망 기반 학습
- 결과: 학습된 모델 (예측 함수)
- 활용: 새로운 데이터에 대해 예측 또는 분류

### ML vs DL

![[002_dl.png]]

`ML`
1. 데이터 준비
2. 피처 추출(분석가 개입)
3. 피처 선택(분석가 개입)
4. 모델 학습
5. 처리

`DL`
1. 데이터  준비
2. 내부 신경망 처리(분석가의 개입이 필요 없음)
3. 모델 학습
4. 처리

**정형 데이터 분석은 ML, 비정형 데이터는 DL**

### ML vs Statistics

통계 분석
- 기술 통계 분석: 주어진 자료의 특성을 그대로 기술
- 추론 통계 분석: 수학 방정식의 형태의 모델로 가정

현재 시점에서 추론 통계는 머신 러닝으로 모두 대체가능


### 예측형 AI vs 생성형 AI

`예측형`
- 대용량 데이터(구조화 데이터: 테이블, 수치) + 학습 --> 분류 / 예측

`생성형`
- 대용량 데이터(비구조화 데이터: 텍스트, 이미지, 오디오) + 학습 --> 생성

둘의 가장 큰 차이점은 판단이냐 생성이냐 차이

![[004_생성형vs예측형.png]]

- 비즈니스 관점에서는 일관성과 재현성이 보장되어야 함. 현업에서는 두 모델의 단점을 섞어서 사용하는 하이브리드 방식을 사용.


## 머신러닝 기법

Target(Y) 존재 유무로 판단.

Y가 존재: Supervised Learning(지도 학습)
- Classification(분류 분석): 범주형
- Regression(회귀 분석): 연속형
Y가 존재하지 않음: Unsupervised Learning(비지도 학습)
- Clustering(군집 분석)
- Association(연관 분석)
- Dimension Reduction(차원 축소)

### Classification vs Regression

| 구분      | Classification                          | Regression                      |
| ------- | --------------------------------------- | ------------------------------- |
| 목적      | 어떤 범주에 속하는지 예측                          | 연속적인 숫자 값을 예측                   |
| 출력      | 클래스 / 범주                                | 실수 값                            |
| 예시      | 고양이/개, 스팸/정상                            | 집값, 온도, 매출 등                    |
| 대표 알고리즘 | Logistic Regression, SVM, Decision Tree | Linear Regression, Ridge, Lasso |

예시) 주식

### Decision Tree

- 독립변수와 종속변수 관계성을 나무구조로 도표화 하여 분류와 예측을 수행하는 분석기법
- 분석결과/이유가 단순하고 직관적이라 다른 사람에게 설명할 때 가장 좋은 기법
- 다른 예측 기법에 비해 예측력이 떨어짐

### Decision Tree 분리 기준

- 원리: 목표변수의 분포를 가장 잘 구별해 주는 설명변수와 절단값(Threshold)를 찾아 자식마디를 형성
- 기준값: 순수도(purity) 또는 불순도(impurity)에 의해 측정
- 부모마디의 순수도에 비해서 자식 마디들의 순수도가 증가하도록 자식마디를 형성

### 순수도 측정 지표

- 범주형: 목표 변수 비율(ratio)에 기초하여 분리
	- 지니 지수, 엔트로피 지수, 카이제곱 통계량
- 연속형: 목표 변수 평균에 기초하여 분리
	- MSE 감소량, 분산의 감소량

### Ensemble

여러 개의 Weak Model을 조합/결합하여 최적의 모델을 만드는 것
- 단일 모델의 약점을 다수의 모델들을 결합하여 보완
- 여러 개의 Decision Tree를 결합하여 과적합을 완화하고 예측력을 높임. 단, 모델의 설명력은 감소
- 다양한 모델 또는 서로 다른 학습 결과를 결합하여 일반화 성능을 향상

### Ensemble 유형

Base Ensemble
- Voting
- Bagging
- Boosting
Meta Ensemble
- Stacking

`Voting`
- 서로 다른 알고리즘이 같은 학습 데이터셋에 대해 학습하여 예측
- 범주형 타겟은 다수 투표 또는 확률 평균으로 결합
- 연속형 타겟은 Average로 최종 모델 생성

`Bagging`
- 단일 알고리즘의 여러 개 샘플데이터로 학습
- 무작위로 복원 추출하여 샘플을 추출하는 방식으로 여러 샘플 데이터 Set을 만들어 학습하는 방식
- 개별적인 예측 결과를 다수 투표 또는 Average로 결합 (Random Forest)

`Boosting`
- 틀린 걸 집요하게 다시 배우는 전략
- 여러 개의 모델이 순차적으로 학습
- 대체적으로 예측 성능이 뛰어나 앙상블 모델링 주도

`Stacking`
- 기본 모델들의 예측 결과를 독립변수로 활용하여 최종 예측을 수행하는 기법
- Overfitting 이슈로 신중하게 고려해야 함.
- 각 모델별 예측결과를 독립변수로 재정의
- K-Fold CV 기반으로 진행 필요

### Boosting

Gradient Boost: 이전 모델의 예측 오차를 순차적으로 학습해서 손실을 점진적으로 최소화하는 앙상블 모델

Random Forest vs Gradient Boost
- RF: 서로 독립적인 결정트리를 병렬로 학습
- GB: 이전 모델의 예측 오차를 순차적으로 학습

`XGBoost`
- 전체  Depth를 균형있게 해서 트리를 추가
- 안정적, 과적합에 상대적으로 강함
- 계산량이 많음
- 중소규모부터 대규모 데이터까지 안정적인 성능

`LightGBM`
- 손실을 가장 많이 줄여주는 Leaf만 선택하여 분할
- 매우 빠른 학습 속도
- 깊이 한쪽으로 치우쳐 과적합 위험
- 대규모 데이터에서 성능 우수

### Regularization

- 회귀분석은 변수가 많아지면 다중공선성 문제와 과적합 문제가 발생함.
- 따라서 회귀계수 크기를 제한하여 모델의 복잡도를 줄이고, 과적합을 방지하여 일반화 성능을 향상시키는 기법.

`LASSO`
- Y와 관련이 낮은 변수의 회귀계수를 0으로 만듬.
- 설명력이 좋은 회귀계수만을 남김

`Ridge`
- 모든 회귀계수를 0에 가깝게 작게 처리
- 변수 선별 없이 모든 변수에 반영

## 클러스터링

- 유사한 혹은 동질의 데이터끼리 군집(cluster)로 묶어 주는 분석기법
- 결과를 얻기 위해 군집을 선택해야함. 분류는 이러이러한 데이터로 종속변수가 나온다.라는 느낌

### 유사성

1. 거리(Distance)
	- 맨하튼 거리
	- 유클리드 거리
2. K-means
	- 군집 내 데이터의 거리는 최소화 (응집도 최대화)
	- 군집 간 거리는 최대화 (분리도 최대화)

### K-means

1. 초기 중심점 선택 (K개의 중심점을 임의로 선택)
2. 각 데이터와 중심점과의 거리를 계산, 가장 가까운 군집으로 할당
3. 중심점 재설정, 각 군집에 속한 데이터들의 평균을 계산하여 중심점 재설정
4. 각 데이터와 새로 바뀐 중심점과의 거리를 계산, 가장 가까운 군집으로 재할당

중심점이 더 이상 변하지 않을 때까지 또는 변화가 매우 작을 때까지 반복
