# 테트리스 게임 만들기

## 파이썬 pygame 모듈을 이용해서 테트리스 게임을 만듭니다.

### 요구사항

- 가상환경을 활성화한 상태에서 pygame을 설치합니다.
- git branch를 main에서 develop로 전환합니다. (develop 브랜치가 없다면 생성)

### 플레이 방식

1. 떨어지는 블록을 키보드 좌우 화살표 키를 이용해서 좌우로 이동합니다.
2. 위 화살표는 블록의 방향을 시계방향으로 돌리기, 스페이스 키는 바로 떨어지기, 아래 화살표는 하단으로 움직이기
3. 떨어진 블록은 하단에 차례로 쌓고 블록의 열이 맞춰지면 블록이 삭제되는 형식으로 기능을 처리
