### 인터프린터 언어

단순한 한 줄씩 실행 구조가 아닌 중간에 바이트코드라는 중간 표현 단계가 존재
-> 이식성과 재사용성 확보
```text
소스코드(.py) : 개발자 작성
-> 파서 : 문법 분석
-> AST : 추상 구문 트리
-> 바이트코드 생성기 : 중간 표현
-> Python Virtual Machine(PVM) : 결과 출력
```

### AST 사용 목적
- 코드의 구조를 명확하게 보여줌
- 코드 구조를 트리 형태로 조작
- 수많은 개발도구들을 활용하여 코드분석 및 내부 조작

-> 컴파일 과정에서 코드에 문제가 없는지 분석하는 과정에서 AST가 핵심적인 역할
-> 컴파일 과정에서 __pycache__ 저장 (py_compile 모듈)

**AST 예시**
```javascript
const a = 10 + 5; # 자바스크립트

- VariableDeclaration (변수 선언)
- kind: const (상수)
- declarations:
- VariableDeclarator (변수 선언자)
- id: Identifier (식별자)
- name: "a“
- init: BinaryExpression (이항 표현식)
- left: Literal (리터럴)
- value: 10
- operator: "+“
- right: Literal (리터럴)
- value: 5
```

### ByteCode
```py
import dis

def add(x, y):
    return x + y

dis.dis(add) # 바이트 코드 출력

# 아래는 위 코드를 바이트 코드로 표현한 것
3 0 RESUME 0        # 실행 초기화 (3번 줄)
4 2 LOAD_FAST 0(x)  # 지역 변수 x를 스택에 Push (4번 줄)
  4 LOAD_FAST 1(y)  # 지역 변수 y를 스택에 Push
  6 BINARY_OP 0(+)  # 스택에서 두 값을 pop 한 후 + 연산 수행, 결과 Push
 10 RETURN_VALUE    # 연산결과 반환
```

### 파이썬 실행 구조
소스코드 -> AST -> ByteCode -> 실행결과
    (파싱)   (컴파일)      (실행PVM)

### PVM
바이트코드를 하나씩 읽어 해석하고 실행하는 엔진
스택 기반의 가상 머신

각 명령은 스택 기반으로 동작
바이트코드는 opcode + 인자 구조
